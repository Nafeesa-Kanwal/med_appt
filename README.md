# Stay Healthy - Medical Appointment Booking Platform

Stay Healthy is a full-stack medical appointment platform where patients can book doctor appointments, view doctor profiles, and manage appointments. Doctors can view patient appointments and prescriptions.

## Project Name: med_appt

## Features
- User Authentication (Sign Up / Login with JWT)
- Doctor Search and Filtering
- Appointment Booking (Name, Phone, Date, Time)
- Instant Consultation Form
- Review System
- Profile Management
- Notification System
- SEO Optimized Landing Page

## Tech Stack
- **Frontend:** React.js (Vite), React Router, Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (or JSON for lab)
- **Authentication:** JWT
